# مكة — نظام إدارة مصنع الأبواب

**اسم البرنامج:** مكة · **اسم الواجهة:** المدينة · **الإصدار:** 1.0

نظام متكامل عربي بالكامل (RTL) لإدارة مصنع الأبواب: العمال والحضور والرواتب، العملاء
والموردون والفواتير وكشوف الحساب، المخزون وحركاته، التقارير، والإعدادات.

---

## التشغيل

### على الهاتف (أندرويد / آيفون) والحاسوب (ويندوز)
افتح رابط النظام في المتصفح، ثم:

| المنصة | طريقة التثبيت كتطبيق |
|---|---|
| **ويندوز** | Chrome/Edge ← أيقونة التثبيت في شريط العنوان ← «تثبيت» |
| **أندرويد** | Chrome ← قائمة ⋮ ← «إضافة إلى الشاشة الرئيسية» |
| **آيفون** | Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية» |

بعد التثبيت يعمل النظام **بدون إنترنت** كتطبيق مستقل، وبياناته محفوظة على الجهاز.

### محلياً للتطوير
```bash
python3 -m http.server 8899
# ثم افتح: http://localhost:8899/makkah/
```

### أول دخول
- المستخدم: `admin` — كلمة المرور: `1234`
- **غيّرهما فوراً** من: الإعدادات ← حساب المستخدم.

## البنية المعمارية

فصل كامل بين الواجهة ومنطق العمل وقاعدة البيانات (نمط طبقات على غرار MVVM):

```
makkah/
├── index.html              الهيكل — يُحمّل التطبيق داخل #app
├── manifest.webmanifest    تعريف التطبيق المثبَّت (PWA)
├── sw.js                   عامل الخدمة — التشغيل بدون إنترنت
├── css/app.css             نظام التصميم (ألوان، فاتح/داكن، تجاوب، طباعة)
└── js/
    ├── app.js              الموجّه (Router) + الهيكل + التنبيهات
    ├── core/               ◀ طبقة المنطق والبيانات (لا تلمس الواجهة)
    │   ├── db.js           IndexedDB — المخازن والفهارس
    │   ├── repo.js         قواعد العمل: الرواتب، الفواتير، المخزون، النسخ الاحتياطي
    │   ├── attendance.js   مولّد سجل الحضور اليومي
    │   ├── auth.js         المصادقة (SHA-256)
    │   ├── bus.js          ناقل الأحداث — التحديث اللحظي
    │   ├── ai.js           الذكاء الاصطناعي (اختياري)
    │   └── util.js         أدوات: تواريخ، أرقام، تصدير
    ├── ui/components.js    ◀ مكوّنات مشتركة: نوافذ، جداول، تأكيد، طباعة
    └── features/           ◀ طبقة العرض — شاشة لكل قسم
        ├── dashboard.js  workers.js   ledger.js (محرّك مشترك)
        ├── customers.js  suppliers.js inventory.js
        ├── invoices.js   reports.js   settings.js  assistant.js
```

### كيف تضيف قسماً جديداً؟
1. أنشئ `js/features/myFeature.js` يصدّر `renderMyFeature(container, params)`.
2. أضف سطراً في `ROUTES` وآخر في `NAV` داخل `js/app.js`.
3. أضف مساره في `ASSETS` داخل `sw.js` وارفع رقم `VER`.

لا حاجة لتعديل أي ملف آخر — النظام مصمّم للتوسّع دون إعادة هيكلة.

## الأقسام

### 👷 العمال
- إضافة عامل **بالاسم فقط** → تُنشأ له صفحة مستقلة بسجل شهري.
- **لا يُنشأ حضور الشهر مسبقاً.** عند بلوغ الوقت المحدد في الإعدادات (افتراضياً 08:30)
  يُنشئ النظام سجل **ذلك اليوم فقط** لكل العمال بحالة «حاضر» افتراضياً.
- تُغيَّر حالة الغائب ثم يُضغط **حفظ** — والراتب يتحدث فوراً دون انتظار نهاية الشهر.
- لكل يوم: ساعات إضافية، سلفة، خصم، ملاحظة.
- **معادلة الراتب:** `أيام الحضور × الأجر اليومي + الساعات الإضافية × أجر الساعة − السلف − الخصومات`
- أرشيف كامل لكل الشهور السابقة مع التعديل والحذف وطباعة كشف الشهر.

### 🤝 العملاء · 🏭 الموردون
يشتركان في محرّك واحد (`ledger.js`) مع اختلاف الاتجاه:
- صفحة مستقلة لكل جهة: الإجمالي، المدفوع، المتبقي، آخر فاتورة، آخر دفعة.
- فواتير بترقيم تلقائي (`INV-2026-0001` / `PUR-2026-0001`)، بنود، دفعات جزئية أو كاملة.
- **تتبّع الكميات:** المطلوب / المسلَّم (أو المستلَم) / المتبقي لكل بند.
- **كشف حساب** بالرصيد السابق والجاري مع تحديد فترة بين تاريخين.
- طباعة وتصدير PDF للفواتير وكشوف الحساب.
- خاص بالموردين: نوع الشركة (خشب، صاج، بوية…)، إرفاق صورة الفاتورة،
  و**قراءة الفاتورة آلياً** بالذكاء الاصطناعي مع **عرض النتائج للمراجعة قبل الحفظ**.

### 📦 المخزون
- أقسام مستقلة + إضافة أقسام جديدة. لكل مادة صفحة تعرض الرصيد وكل الحركات.
- **الربط التلقائي:** فاتورة شراء ← إدخال، فاتورة بيع ← إخراج.
  تعديل الفاتورة يعكس الحركات القديمة ويعيد ضبط الرصيد تلقائياً.
- تنبيه عند بلوغ الحد الأدنى + تقارير (الكميات الحالية، النواقص، الحركات بين تاريخين).

### 📊 التقارير
الأرباح والخسائر · المبيعات · المشتريات · الرواتب · الحضور · المخزون —
مع تصفية (يوم/أسبوع/شهر/سنة أو تاريخين) وتصدير **PDF** و**Excel/CSV**.

### ⚙️ الإعدادات
اسم المصنع والعملة · وقت سجل الحضور · الوضع الفاتح/الداكن · تغيير المستخدم وكلمة المرور ·
مفتاح الذكاء الاصطناعي · **النسخ الاحتياطي** (تلقائي يومي + تصدير/استيراد ملف) · سجل النشاط.

### ✨ المساعد الذكي
- **بحث شامل فوري** في كل بيانات النظام (يعمل بدون إنترنت).
- إجابة عن أسئلة حرة عبر Claude عند إضافة المفتاح؛ وبدونه يعرض **ملخصاً محلياً** بدل الاعتذار.

## نظام التعديل الشامل
كل سجل محفوظ قابل للتعديل: زر **تعديل** يفتح نفس الاستمارة معبأة، مع **موافق** للحفظ
و**إلغاء** للتراجع. بعد الحفظ تُحدَّث كل الحسابات المرتبطة تلقائياً (الرواتب، المخزون،
أرصدة العملاء والموردين، ولوحة التحكم) عبر ناقل الأحداث.

## ملاحظات
- **البيانات محلية على كل جهاز.** لنقلها بين الأجهزة استخدم تصدير/استيراد النسخة الاحتياطية
